# MaxStream

Небольшое одностраничное приложение в стиле Netflix для локального выбора фильмов и сериалов. Можно сохранять свою оценку и короткий отзыв в `localStorage`, поэтому данные остаются на устройстве пользователя.

## Как запустить

1. Установите Node.js (подойдет любая LTS-версия).
2. В корне проекта выполните `npm start` — поднимется локальный сервер на `http://localhost:8000`.
3. Откройте страницу и пользуйтесь поиском, фильтром по типу и сортировкой.
4. На карточке выберите оценку с помощью шкалы и при желании оставьте комментарий.
5. Нажмите «Сохранить», чтобы оставить оценку/отзыв локально. Кнопка «Очистить» удаляет сохраненные данные для конкретного тайтла.

Все отзывы и оценки сохраняются в `localStorage` под ключом `maxstream-state`. Незнакомые маршруты автоматически возвращают главную страницу, чтобы избежать ошибки «Not Found» при обновлении вкладки.
