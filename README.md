# Глубокая вода

Интерактивная WebGL-сцена на Three.js с реалистичной водой, динамическими погодными пресетами и стилизованным кораблём.

## Возможности
- Шейдер воды из three.js с высоким разрешением нормалей, туманом и тон-маппингом.
- Переключение погоды: штиль, бриз, шторм, закат с туманом.
- Тонкие настройки волн, скорости симуляции и количества пены.
- Добавление/удаление корабля, изменение его масштаба, плавание и раскачка по волнам.
- Управление камерой (OrbitControls) и адаптивное освещение неба.

## Запуск
Приложение не требует сборки. Достаточно запустить любой статический сервер из корня:

```bash
# Например, с помощью Python
python -m http.server 4173
# или npx serve, если установлен Node.js
npx serve
```

После запуска откройте страницу в браузере по выведенному адресу (например, http://localhost:4173).
